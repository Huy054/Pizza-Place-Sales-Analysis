# Bộ dữ liệu nguồn

Dự án dựa trên bộ dữ liệu Pizza Place Sales năm 2015, gồm bốn bảng:
`orders`, `order_details`, `pizzas`, `pizza_types`.

**Bốn file CSV nguồn không được đóng gói trong ZIP này**, vì chúng chưa được cung cấp ở phiên làm việc này. Nếu repository GitHub hiện tại của bạn đã lưu các file dữ liệu, **hãy giữ nguyên**.

Để tái lập trên SQL Server, nhập bốn bảng từ dữ liệu nguồn; kiểm tra kỹ dấu thập phân của `pizzas.price` vì bộ dữ liệu từng gặp lỗi do cách import/locale.

Ghi nguồn của dữ liệu và giấy phép sử dụng theo nơi tải dữ liệu ban đầu. Không tự nhận quyền sở hữu dữ liệu nguồn.
